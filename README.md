# Minos — moderacja komentarzy (WordPress)

Wtyczka WordPress, która wysyła nowe komentarze do bramy Wergiliusz w celu automatycznej oceny i stosuje werdykt odesłany przez bramę na podpisany webhook: publikuje komentarz, publikuje go z zamaskowanymi fragmentami albo zatrzymuje do moderacji. Wtyczka jest częścią projektu Minos i jest udostępniana na licencji GPL-2.0 (zob. plik `LICENSE`).
